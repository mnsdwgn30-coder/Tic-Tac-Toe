# ✕ Tic-Tac-Toe ◯

An ultra-clean, modern, Google-styled **Tic-Tac-Toe** game with 2-Player mode and Computer AI (Easy, Normal, and Hard / Minimax).

## ✨ Features
- **👥 2 Players Mode (Pass & Play):** Play locally with custom editable player names.
- **🤖 vs Computer Mode:**
  - 🟢 **Easy:** Beginner AI for casual play.
  - 🟡 **Normal:** Balanced AI with smart blocking.
  - 🔴 **Hard:** Unbeatable Minimax AI algorithm.
- **✏️ Editable Names:** Customize Player 1 and Player 2 names in real-time.
- **⚡ Live Scoreboard:** Tracks Player 1 wins, Player 2 / Computer wins, and Ties.
- **🔊 Zero-Latency Sound FX:** Synthesized Web Audio API sound effects with mute toggle.
- **🎨 Google Material Aesthetic:** Responsive, dark-mode glassmorphic interface built with pure Vanilla HTML5, CSS3, and JavaScript.

## 🚀 How to Run Locally
1. Clone this repository:
   ```bash
   git clone https://github.com/mnsdwgn30-coder/Tic-Tac-Toe.git
   ```
2. Open `index.html` directly in your web browser.
